### “The test automation toolbox: exploring frameworks built on WebDriver — the API for browser automation”

[Pallavi Sharma](https://www.linkedin.com/in/musepallavi/)

This session explores the power and versatility of [WebDriver](https://www.selenium.dev/documentation/webdriver/), the standard [API](https://en.wikipedia.org/wiki/API) for browser automation, and its broad adoption across programming languages. We’ll dive into the WebDriver ecosystem, examining open-source frameworks built in Java, C#, Ruby, Python, and JavaScript. Attendees will gain insights into how these frameworks leverage WebDriver, the challenges of cross-language implementation, and best practices for choosing the right tool. We’ll also assess framework health using key [GitHub](https://github.com/) metrics and discuss ways to contribute to the open-source automation community. Whether you’re a tester, developer, or QA engineer, this talk will help you navigate the test automation toolbox more effectively.
